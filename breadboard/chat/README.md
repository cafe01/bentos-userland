# `chat` breadboard

The chat turn drawn as a **circuit** — logical components wired in the shell. Each component is a `.sh` file with a stdin/stdout contract; the executables it calls (`chat-codec`, `chat-render`, `llm`) are *physical* parts abstracted behind a *logical* role, so the schematic never couples to invocation syntax.

The skeleton is invariant — `input → [turn] → output` — and every logical component lives on one of those three axes.

```
            INPUT                 TURN  (the black box)              OUTPUT
   chat-prompt.sh  (live)   ┐                                    ┌  chat-render.sh
   chat-fixture.sh (synth)  ┴─►  transcript ─►  chat-turn.sh ─►  ┤  (live, human)
                                 (ChatMessage     delta as a     └  chat-codec fold
                                  JSONL = state)  ChatEvent stream    (persist → transcript)
```

| file | axis | in → out |
|---|---|---|
| `chat-prompt.sh`  | input  | text → one user `ChatMessage` |
| `chat-fixture.sh` | input  | fixture name → canned message(s) — the signal generator |
| `chat-turn.sh`    | turn   | transcript (context) → assistant `ChatEvent` delta |
| `chat-render.sh`  | output | event stream → styled human text |
| `chat.sh`         | —      | the schematic: wires the three; `dispatch_delta` is the one logical "fate of the delta" (render + fold; tomorrow + `tx commit`) |

The **turn** is the generic agent-loop, chat-configured: its internal `next_state` is the state machine (`infer | tools | done`); chat-without-tools is the degenerate `infer`-only branch. Its `infer` is a fake event generator now — swap that one function body for `llm …` to plug the real device in at the edge, last.

## Run it

```sh
./chat.sh "o que é o BentOS?"     # full circuit, live input
./chat.sh                          # synthetic input (no human)
./chat-turn.sh < fixtures/greeting.jsonl   # the heart in isolation: branch 'infer'
./chat-turn.sh < fixtures/answered.jsonl   # branch 'done' (terminal → empty)
```

Fixtures under `fixtures/` are generated by the codec, never hand-written.
